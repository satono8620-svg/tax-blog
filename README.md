# tax-blog

税務ブログ記事の原稿置き場です（非公開）。

## フォルダの使い分け

| フォルダ | 入れるもの |
|---|---|
| `drafts/` | 書きかけの記事 |
| `published/` | 公開済みの記事（公開したら drafts から移動） |
| `templates/` | 記事のひな形 |
| `notes/` | ネタ帳・調べものメモ |

## 記事の始め方

1. `templates/article-template.md` をコピーする
2. `drafts/2026-11-01-記事のテーマ.md` のように「日付-テーマ」で名前をつける
3. 書き上がって公開したら `published/` へ移動する

## 記事を書くときの約束

- 顧問先の名前・金額など、個人や会社が特定できる情報は書かない（事例は必ず加工する）
- 税制は毎年変わるので、「何年度の情報か」を記事に明記する
- 根拠（条文・通達・国税庁のページ）を記事末に残す
