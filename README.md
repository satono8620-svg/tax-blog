# tax-blog

税務ブログの「設定」と「資料」の置き場です（非公開）。

## 役割分担

| 置き場所 | 入れるもの |
|---|---|
| GitHub（このリポジトリ） | 書き方のルール、記事のひな形、リサーチのメモ |
| Notion「税務ブログ」ページ | 記事の下書きと完成品 |

Notion「税務ブログ」：https://app.notion.com/p/4092ecf8df2381b99b19f781085d7f88

## フォルダ

| フォルダ・ファイル | 入れるもの |
|---|---|
| `CLAUDE.md` | 記事の書き方のルール（Claude が毎回読み込む） |
| `templates/` | 記事のひな形 |
| `notes/` | ネタ帳・リサーチのメモ |

## 新しい記事を書くとき

1. Claude のセッションを始めるときに、リポジトリで `tax-blog` を選ぶ
2. テーマを伝える（リサーチ → 執筆 → Notion「税務ブログ」の下にページを作成、まで Claude が行う）
3. 手直しは Notion で行う。Claude に直してもらうときは「Notion の〇〇のページを直して」と伝える
4. 守ってほしい書き方が新しく出てきたら「ルールに追加して」と伝える（`CLAUDE.md` に書き足す）
